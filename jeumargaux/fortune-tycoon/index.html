Fortune Tycoon

Le grand jeu de l'immobilier · Affrontez l'ordinateur · v2.1.0

Règles : lancez les dés, achetez les propriétés libres, réunissez un groupe de couleur pour construire maisons et hôtels et faire grimper les loyers. Départ : +200 € à chaque passage ; Prison : sortez avec un double, 50 € ou une carte. Une propriété refusée part aux enchères ; sans argent, c'est la faillite.
Nouveau façon jeu vidéo — 📈 Bourse : achetez/vendez 6 actions dont les cours bougent chaque tour (actualités, krachs…) ; 🏦 Banque : dépôts à 5 % d'intérêts, à l'abri du Voleur ; 🃏 Boutique de cartes : missile, tortue, barrière, voleur, dés pipés, cartes rouge/noire ; 🎟️ Loterie : tirage tous les 5 tours. Cliquez sur une case pour voir ses détails.
